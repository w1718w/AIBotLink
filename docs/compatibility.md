# 兼容性与验证

本页记录通用协议边界与验证层级，不包含机器人账号、会话标识、凭据或个人运行记录。真实握手、目录查询、本地假协议测试和完整任务 E2E 分别判断。

## 版本与测试环境

| 项目 | 范围 |
|---|---|
| Node.js | 要求 >=22.19；开发检查使用 Node 25 |
| Codex | 已探测 CLI 0.153.2，stdio App Server |
| DSH | 已探测 Host 0.2.1-rc.2；Host 桥为首选接入，保留 ACP 兼容路径 |
| QQ | 官方机器人 C2C；群聊仅有授权接入代码，待完整验收 |
| 部署 | Windows；单机部署；其他系统及多机部署未完整验收 |

依赖版本由 package.json 与锁文件定义。网关本地测试使用假 stdio、HTTP/SSE 和假 Host，共 19 项通过；不调用模型或真实 QQ。桥接端是实现 DSH Host 桥接接口的外部组件，其实现、测试与原生 Host 版本适配不在本仓库范围内，需另行验收。持续事件流与最新集成修改仍需随目标发布目录重新加载和验收；本地通过不能替代真实 Host 测试。

DSH Host 桥接接口以连接记录 `version: 1` 和初始化 `protocolVersion: 1` 为版本边界；网关只消费接口，不读取原生 Host 版本。接口只接受一个认证客户端；连接断开或请求失败后，未确认任务按未知结果处理，不自动取消原生任务、不重放。具体桥接实现、原生 Host 版本与操作系统差异需分别验收。

## 原生设置与会话边界

模型目录或配置中存在某个模型，不证明当前账号有调用权限。默认提供方跟随原生配置，不为绕过认证失败自动替换提供方；/provider 不负责修复账号凭据。Host 桥的模型/推理选择经桥接接口完成，原生实现可能同步保存默认值，不能承诺只影响当前会话。

独立 Codex 后端可能在任务结束后继续持有已加载线程。/release 停止自有空闲后端，不解除其他客户端的锁，也不证明 Desktop 已获得控制。DSH Host 桥 /release 只断开客户端，不停止 Host、不保证卸载原生会话。线程可读取不能证明 Desktop 侧栏自动归类、移动端同步或跨客户端共同控制。

Codex 0.153.2 空白线程可能尚无可恢复 rollout。兼容重建仅适用于本进程确认从未尝试提交输入的空白线程；任何提交尝试后均不得当作空白重建。原生写者冲突会明确返回本次未提交，本地测试确认不调用 turn/start、不留下未知提交占位。

DSH ACP 的空白会话关闭后可恢复，但设置可能恢复为默认值；其探测没有声明图片、音频或嵌入上下文输入。该结果不替代 Host 桥验证。所有接入当前只转交文本。

/history 返回 Codex 最近五个 Turn，或 DSH Host 最近快照中的文本，不提供完整历史翻页。目录可分页不代表所有历史记录都能一次读回。

## 测试与临时兼容

网关在自身仓库根目录执行：

```powershell
npm ci
npm run build
npm test
```

`npm test` 先构建，再运行 `dist/test/*.test.js`，共 19 项。它只覆盖网关，使用本地假协议与假 Host，不连接真实 QQ、不调用模型，也不包含桥接端测试；桥接端按 [DSH Host 桥接接口](dsh-bridge-protocol.md) 自行测试与验收，不能把网关本地测试当作接口实现或任务的完整验收。

显式运行的 TEST_ONLY 原生控制探测与推理 smoke 脚本另行判断；推理脚本会调用原生模型，不由启动流程自动执行。TEST_FIXTURE 标记假账号和假协议数据，不能作为生产配置。COMPAT 精确标记已观察到的原生版本行为及移除条件，不是通用静默兜底；DSH ACP 的兼容规则不适用于 Host 桥接接口。临时实验必须标识且不混入默认配置。文案只有中文资源与本机覆盖，不声明完整 i18n。

## 当前缺项与发布验收

- 文件、图片、语音及其他 IM 尚未接入。
- DSH ACP 路径没有 Host 桥提供的历史、分支、Steer、Compact 和权限修改能力。
- 独立 Agent Preset 入口、Codex 完整 Permission Profile 选择和聊天内工作目录切换未实现。
- 附加已运行 Codex 后端、跨后端抢锁不是已实现能力。
- 分发与安装：尚无公开分发包；从仓库克隆、构建和配置的完整流程需按目标机器验收。
- 部署边界：网关安装位置由使用方决定；配置、状态与日志必须位于仓库外；自启脚本注册登录计划任务与配置页快捷方式，注册成功不等于登录自启已验收，须在目标机器下次登录或重启时确认。
- DSH Host 桥接接口：网关只定义并消费回环 HTTP/SSE 契约；桥接端实现、原生 Host 版本与操作系统差异需分别验收，不能把接口连通或本地假 Host 测试当作模型任务 E2E 通过。

发布前应按目标版本和目录重新验证 Host 加载、DSH 任务终态及 QQ 回复、历史分支、工具/权限、停止、审批、新版菜单、跨提供方、交接、故障恢复和自启。不能将局部通过、接口连通或桥接端注册成功扩大为完整系统 E2E 通过。
